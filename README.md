# Sasha's Portfolio

A simple personal site to showcase my engineering projects for internship applications.

## Running it in a Codespace

1. Click **Code → Codespaces → Create codespace on main**.
2. Once it opens, right-click `index.html` and choose **Open with Live Server** (or click **Go Live** in the bottom bar).
3. A preview opens in a new tab and refreshes every time you save.

## Files

- `index.html` – page content (edit your name, projects, links here)
- `style.css` – colors, fonts, layout
- `script.js` – small extras (footer year, mobile menu)

## Publishing (free)

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / root → Save.
Note: GitHub Pages on a private repo needs a paid plan; make the repo public or use Netlify/Vercel instead.
